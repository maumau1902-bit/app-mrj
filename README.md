# Pulse Analytics — downloads

Pulse Analytics 0.3.0 — versão de teste para Windows 10/11 x64.

[Baixar instalador](https://github.com/maumau1902-bit/app-mrj/raw/refs/heads/pulse-downloads/Pulse-Analytics-Setup-0.3.0-x64.exe)

Abas para cadastrar, editar e alternar empresas. Nome, identificação, cidade/UF, identificador Mithra, observações e logo próprios. A empresa selecionada permanece ao reabrir. Novas empresas começam sem dados; a demonstração pode ser ativada no cadastro.

Dados salvos neste dispositivo; login e conexão real ao Mithra ainda pendentes. Instalador sem assinatura digital; Windows pode indicar editor desconhecido. Atualização interna ativada: catálogo Ed25519 assinado, SHA-512, aviso ao abrir, download, adiamento e instalação com reinício. A assinatura das atualizações é independente de Authenticode; o Windows ainda pode indicar editor desconhecido. Instale sobre a versão anterior, mantendo o perfil do aplicativo.

Validados: testes unitários, desktop Electron, quatro empresas, persistência, isolamento de logos e resoluções de tela. A instalação desta versão ainda precisa de teste no Windows.
